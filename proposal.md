# Snake Game

## Repository
<https://github.com/GitName654/Final-Project-Proposal---Snake-Game.git>

## Description
1-2 sentence description of what it will do and how it relevant to media and digital arts.

It will be a simple snake game where the snake grows longer the more points it consumes and dies once it collides into an object. The functions will feature particle and collision systems that we've learned in class.

## Features
- Feature 1
	- Point system
- Feature 2
	- Collision effects
- Feature N 
	- Random Point spawn locations

## Challenges
- Learn how to make objects/particles die on collision
- Learn how to have the points spawn on locations that aren't occupied by the snake
- Adding player movement controls

## Outcomes
Ideal Outcome:
- A snake that grows longer with each point consumed, and dies when the head of the snake collides with the walls of the game or itself, with a point system

Minimal Viable Outcome:
- A snake that grows in length, and dies on collision

## Milestones

- Week 1
  1. Goal 1: Create the game display
  2. Goal 2: create a moving particle

- Week 2
  1. Goal 1: add a point that spawns on the game board
  2. Goal 2: allow the particle to grow in length on collision with the particle

- Week N (Final)
  1. Goal 1: add death collision for the snake
  2. Goal 2: create a point system and ending screen
